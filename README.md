## About JFLAP

**JFLAP (Java Formal Languages and Automata Package)** is an interactive educational software tool designed for experimenting with formal languages and automata theory.

It provides a visual environment to design, simulate, and analyze different computational models studied in Computer Science.

### Key Capabilities

- **Graphical Automata Design:** Design DFA, NFA, PDA, and Turing Machines.
- **Interactive Simulation:** Execute inputs using Single Step, Fast Run, and Multiple Run.
- **Formal Grammar Tools:** Define regular and context-free grammars and perform grammar transformations.
- **Parsing Algorithms:** Construct and visualize LL(1) parsing tables and CYK parsing.
- **Automated Conversions:** Convert between Regular Expressions, Finite Automata, Grammars, and Pushdown Automata.

## Topics Covered

This repository contains **30 JFLAP files** covering fundamental concepts of Theory of Computation.

### 1. Deterministic Finite Automata (DFA)
- Counting conditions and parity.
- Divisibility checking.
- Prefix, suffix, and substring recognition.
- Exact pattern recognition.

### 2. Non-Deterministic Finite Automata (NFA)
- Branching paths.
- State guessing.
- Pattern recognition using multiple possible paths.

### 3. Regular Expressions and Regular Grammars
- Regular language representation.
- Right-linear grammars.
- Conversion between regular expressions, grammars, and automata.

### 4. Finite State Machines with Output
- Mealy Machines.
- Moore Machines.
- Pattern detection with output generation.

### 5. Context-Free Grammars (CFG)
- Generating languages such as `0^n1^n`.
- Balanced strings.
- Palindrome recognition.

### 6. Chomsky Normal Form (CNF)
- CFG transformations.
- Productions of the form `A -> BC` and `A -> 0`.

### 7. Pushdown Automata (PDA / NPDA)
- Stack-based language recognition.
- Acceptance by final state or empty stack.
- CFG and NPDA conversions.

### 8. Parsing Algorithms
- First and Follow sets.
- LL(1) predictive parsing.
- LR parsing.
- CYK parsing algorithm.

### 9. Turing Machines
- Single-tape Turing Machines.
- Multi-tape Turing Machines.
- Building blocks and tape operations.

### 10. Other Models
- Unrestricted Grammars.
- L-Systems.
